Frame Format:
1. Standard H2DR (Host-to-Device Request):
   [0..3]: "H2DR" (ASCII 0x48, 0x32, 0x44, 0x52)
   [4]   : Command Opcode
   [5]   : Subcommand
   [6]   : Parameter / Sequence
   [7]   : Checksum = sum(byte[0..6]) & 0xFF (f.a)

2. 0xA5 Dialect:
   [0]   : 0xA5 sync byte
   [1]   : Opcode (0x54 Running, 0x62 HeartRate, 0x55 Weather)
   [2..] : Payload

Summary of Command Codes:
- 0x9F : Get Total Steps, Distance, Calories, Active Time
- 0x54 : Toggle Running Workout + GPS Mode (0xA5 0x54 [0/1])
- 0x7C : Request Block Data Sync ([0x7C, 0x00, dataIndex, 4B address])
         - 0x05: Sport records
         - 0x06: Dynamic Heart Rate records
         - 0x0E: GPS Track coordinates
         - 0x0C: Diagnostic Logs
- 0x9B : Get EPO Satellite Ephemeris Info
- 0x90 : Time Sync Handshake (followed by 11-byte Calendar payload)
- 0x62 : Toggle Continuous Heart Rate (0xA5 0x62 [0/1] 00 00 00 00 00)
- 0xB7 : Raise-To-Wake Gesture Light (H2DR 0xB7 0x00 [0/1])
- 0xB0 : Screen Backlight (H2DR 0xB0 0x00 [0/1/2])
- 0xB2 : Anti-Lost Vibration (H2DR 0xB2 0x00 [0/1])
- 0x9C : Camera Screen Control (H2DR 0x9C 0x00 [0x18/0x00])
- 0x89 : Device Reboot (H2DR 0x89 0x01 0x00)
