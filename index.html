WeLoop Hey 3S 时间同步

基于 Web Bluetooth，协议反编译自 WeLoop 官方 app。无需安装任何东西，仅用 Chrome / Edge。

1. 选择设备并同步

点击后 Chrome 会弹出蓝牙设备选择框，选 WeLoop Hey 3S。状态: 未连接

2. 日志

说明 / 故障排除

• 必须用 Chrome / Edge / Opera（安卓 Chrome 也行）。Safari、Firefox 不支持 Web Bluetooth。
• 页面要用 https:// 或 file:// 打开（直接双击本 HTML 文件即可）。
• 安卓 Chrome：需 Android 6.0+，位置权限要开（BLE 扫描依赖位置权限）。
• 连不上？先在系统蓝牙设置里忽略/取消配对 Hey 3S（Web Bluetooth 不能用已配对设备），再重试。
• 手表时间没变？断开手表蓝牙重连，部分固件要重连才刷新显示。
• 选择框里看不到 Hey 3S？点右下角"没有看到我的设备？"，或靠近手表、给手表亮屏。
